# Convencions · extensión Operate

- **Tesis:** leer la base madre versionada y la integración explícita del repositorio con autoridad Phantom; la activación de una herramienta nunca equivale a adopción.
- **Mundo heredado:** paneles del canvas, Centro de Plugins, navegación/paleta, EmptyState, controles etiquetados y glifos Lucide. PRODUCT.md y DESIGN.md mantienen su alcance. Mismos planos ciruela, tokens y foco; espacio y tipografía separan el contenido.
- **Recorrido:** Centro → activar por proyecto → Base madre / versiones o Proyecto / integración → índice filtrable → detalle de qué, cuándo, por qué, cómo comprobar y evidencia. Ambas vistas se abren como nodos restaurables.
- **Primer viewport:** identidad de vista, autoridad y contrato, repositorio, navegación y estado real. Backend ausente muestra causa y reintento; con fuente válida muestra base/versión consultada o registro, pin y perfil antes del índice.
- **Forma heredada sin seed:** una caja por panel, sin tarjetas anidadas, gradientes, eyebrows ni barras de categoría. Ancho mínimo cero, texto largo envuelve, teclado y campos etiquetados. No hay convenciones de demostración en producción.
- **Criterio de cierre:** manifiesto, activación aislada, restauración, ruta host ya permitida, contrato validado y ownership, distinción de estados y semánticas, pruebas unitarias y desktop con fixtures completos en ambos tamaños. El controlador ejecuta checks; el padre revisa capturas/detector. No se presume conexión MCP ni aprobación visual.
